## 1. 三種做法，挑一種

打開設定 →「**角色**」分頁 →「**角色工作室**」。

| 做法 | 適合誰 | 你需要準備 | 效果 |
|---|---|---|---|
| **方法 1：用圖片做** | 會畫圖、有現成的角色圖 | 1 張以上的去背 PNG | 程式幫你加上彈跳、搖晃、壓扁、小表情 |
| **方法 2：畫像素精靈圖** | 想做像素風、想要每個動作都自己畫 | 會用像素繪圖軟體 | 每一格都照你畫的播放，最細緻 |
| **方法 3：匯入別人的角色** | 拿到別人分享的角色 | 一個角色資料夾 | 直接能用 |

做好的角色都放在這台電腦的「角色資料夾」：

```
%APPDATA%\tw.deskpet.kankan\skins\
```

在「角色」分頁按「**開啟角色資料夾**」就能打開它。

## 2. 方法 1：用圖片做（最簡單）

### 步驟

1. 準備一張角色的圖，要求如下：
   - **PNG、背景透明（去背）**：背景不透明的話，桌面上會出現一個方框
   - **角色面向左邊**：往右走的時候，程式會自動左右翻轉
   - **高度 200～600 像素**：太大浪費記憶體，太小放大會糊
   - **角色的腳貼著圖片下緣**：上下左右不要留太多空白
2. 打開設定 →「角色」→「角色工作室」→「**方法 1**」
3. 輸入名字，按「**閒置 \***」選你的圖。這張一定要有
4. 其他動作的圖**可以不給**，想給的話就依照下一節的表格選
5. 選填「聊天個性」和「角色介紹」
6. 按「**建立角色**」，就會自動切換成你的角色

### 程式會自動加的效果

| 動作 | 效果 |
|---|---|
| 閒置、坐著 | 輕輕的呼吸起伏 |
| 走路 | 一跳一跳、左右擺動 |
| 睡覺 | 微微壓扁，加上 💤 |
| 被拎起來 | 左右晃動，加上 💦 |
| 開心 | 跳起來，加上 ✨ |
| 思考中 | 歪頭，加上 💭 |
| 被摸頭 | 壓扁回彈，加上 💕 |
| 吃點心 | 小小彈跳，加上 🍪 |

有給某個動作的圖時，程式會用那張圖，再疊上這些效果。所以不同動作畫不同表情（例如睡覺時閉眼），效果會更好。

### 小技巧

- **去背工具**：remove.bg、Photoshop、GIMP 或 Krita 的「選取主體」都可以
- **像素風的圖**：建立之後，把 `manifest.json` 裡的 `"pixelated": false` 改成 `true`，放大時才不會糊掉
- **調整大小**：改 `manifest.json` 的 `"height"`（單位是畫面上的像素，預設 128），或是用設定「一般」裡的大小

## 3. 方法 2：畫像素精靈圖

「精靈圖」就是把一個角色的所有動作，畫在同一張大圖的格子裡。

### 步驟

1. 設定 →「角色」→「角色工作室」→「**方法 2**」→「**建立像素範本並打開資料夾**」
2. 資料夾裡會有這些檔案：
   - `sprite.png`：**在這張上面畫**。背景要保持透明
   - `guide.png`：參考格線，每一列一種顏色，深色橫線是地面。可以放在下層當底圖
   - `manifest.json`：角色設定
   - `lines/zh-TW.json`：角色專屬台詞（選用）
   - `README.txt`：簡短說明
3. 用像素繪圖軟體打開 `sprite.png`，例如 [Aseprite](https://www.aseprite.org/)、[LibreSprite](https://libresprite.github.io/)，或網頁版的 [Piskel](https://www.piskelapp.com/)
4. 畫好後存檔（PNG，透明背景）
5. 回到 desk-pet，按「**重新掃描**」，選你的角色

### 格子的規則

```
      第 0 格   第 1 格   第 2 格   第 3 格
第 0 列  idle     idle     idle     idle      ← 閒置
第 1 列  walk     walk     walk     walk      ← 走路
第 2 列  sleep    sleep                       ← 睡覺
第 3 列  drag     drag                        ← 被拎起來
第 4 列  react    react    react    react     ← 開心
第 5 列  think    think    think    think     ← 思考中
第 6 列  pet      pet                         ← 被摸頭
第 7 列  eat      eat                         ← 吃點心
第 8 列  sit      sit                         ← 坐在視窗邊
```

- 範本每一格是 **32×32** 像素，會放大 4 倍顯示
- 想畫更細緻的話可以改成 64×64，做法是：
  1. 把圖片尺寸改成兩倍
  2. 把 `manifest.json` 的 `frameWidth`、`frameHeight` 改成 64
  3. 把 `scale` 改成 2
- **角色面向左邊**，腳踩在 `guide.png` 的地面線上
- **每一格的角色位置要對齊**，不然播放時會抖。可以用洋蔥皮（onion skin）功能對照前一格

### 格數可以自己決定

`manifest.json` 裡每個動作都有 `frames`（格數）和 `fps`（每秒幾格）：

```json
"walk": { "row": 1, "frames": 4, "fps": 8 }
```

- 只畫了 2 格，就把 `frames` 改成 2
- 不想畫某個動作，就把那一行刪掉。程式會用相近的動作代替（見第 4 節）
- `row` 要跟圖上的列數對應，從 0 開始數

### 想看範例？

repo 裡的三個內建角色都是用程式畫的，可以參考：

- `scripts/gen-default-skin.mjs`：柑柑（32×32）
- `scripts/gen-kanade-skin.mjs`：小奏（32×32）
- `scripts/gen-shiori-skin.mjs`：栞（64×64 高清）

## 4. 角色會用到的動作

| 名稱 | 什麼時候出現 | 沒有的話用什麼代替 |
|---|---|---|
| `idle` | 平常待著（**必要**） | ─ |
| `walk` | 走來走去 | idle |
| `sleep` | 你離開電腦太久 | idle |
| `drag` | 被滑鼠拎起來、從視窗掉下來 | idle |
| `react` | 被點、完成待辦、開心 | idle |
| `think` | 等 Claude 回覆 | idle |
| `pet` | 被摸頭 | react |
| `eat` | 吃點心 | react |
| `sit` | 坐在其他視窗上 | idle |

**最少只要 `idle` 就能用。**建議至少畫 `idle`、`walk`、`sleep`、`react` 四個。

## 5. manifest.json 欄位說明

### 精靈圖模式

```json
{
  "name": "我的角色",
  "author": "你的名字",
  "image": "sprite.png",
  "frameWidth": 32,
  "frameHeight": 32,
  "scale": 4,
  "names": { "zh-TW": "我的角色", "ja": "わたしのキャラ", "en": "My Pet" },
  "bio": { "zh-TW": "角色介紹…" },
  "persona": { "zh-TW": "你是……" },
  "animations": {
    "idle": { "row": 0, "frames": 4, "fps": 3 },
    "walk": { "row": 1, "frames": 4, "fps": 8 }
  }
}
```

### 圖片模式

```json
{
  "name": "我的角色",
  "mode": "image",
  "height": 128,
  "pixelated": false,
  "images": {
    "idle": "idle.png",
    "sleep": "sleep.png"
  },
  "names": { "zh-TW": "我的角色" },
  "persona": { "zh-TW": "你是……" }
}
```

### 欄位一覽

| 欄位 | 必要 | 說明 |
|---|---|---|
| `name` | ✅ | 名字（找不到對應語言時使用） |
| `author` | | 作者 |
| `names` | | 各語言的名字：`zh-TW`、`ja`、`en` |
| `bio` | | 各語言的角色介紹，顯示在設定的「關於」 |
| `persona` | | 各語言的聊天個性（見第 7 節） |
| `mode` | | 填 `"image"` 就是圖片模式；不填就是精靈圖模式 |
| `image` | 精靈圖 ✅ | 精靈圖檔名 |
| `frameWidth` / `frameHeight` | 精靈圖 ✅ | 每一格的寬、高（像素） |
| `scale` | | 精靈圖放大幾倍（預設 4） |
| `animations` | 精靈圖 ✅ | 每個動作的 `row`（第幾列）、`frames`（幾格）、`fps`（每秒幾格） |
| `images` | 圖片 ✅ | 每個動作的圖片檔名，至少要有 `idle` |
| `height` | | 圖片模式在畫面上的高度（預設 128） |
| `pixelated` | | 放大時要不要保持像素顆粒感（精靈圖預設 `true`，圖片模式預設 `false`） |

- 圖片支援 PNG、JPG、WebP、GIF（GIF 只會顯示第一格）
- 檔名只能指向**同一個資料夾**裡的檔案
- **資料夾名稱**就是角色 id，只能用英文、數字、`-` 和 `_`

## 6. 寫角色專屬台詞

在角色資料夾裡建立 `lines` 資料夾，每個語言一個檔案：

```
my-pet/
└─ lines/
   ├─ zh-TW.json
   ├─ ja.json
   └─ en.json
```

內容範例：

```json
{
  "greeting": ["你好！今天也請多指教。", "來了來了～"],
  "click": ["嗯？叫我嗎？"],
  "todo_done": ["完成了！好厲害！"]
}
```

- **寫了的分類會取代共用台詞**，沒寫的分類就沿用共用台詞。所以只寫你想改的就好
- 每個分類是一個字串清單，角色會隨機挑一句
- JSON 的注意事項：
  - 句子之間要加逗號，**最後一句後面不能有逗號**
  - 字串要用**半形**雙引號 `"`
- 改完後到設定 →「台詞」→「**重新載入**」

### 可以用的分類

| 分類 | 時機 |
|---|---|
| `greeting`、`greeting_morning`、`greeting_afternoon`、`greeting_evening` | 啟動、打招呼 |
| `idle` | 定期自言自語 |
| `busy` | 你正在打字或操作時 |
| `away_return` | 你離開後回來 |
| `late_night` | 深夜 23:00～05:00 |
| `todo_done`、`todo_all_done` | 完成待辦、全部完成 |
| `click`、`drag`、`drop` | 被點、被拎起來、被放下 |
| `pet`、`feed`、`feed_full`、`love_up` | 被摸頭、吃點心、吃太飽、好感度升級 |
| `pomodoro_start`、`pomodoro_break`、`pomodoro_break_end` | 番茄鐘 |
| `reminder` | 提醒的開頭（後面會接提醒內容） |

## 7. 寫聊天個性（persona）

填了 Anthropic API 金鑰之後，點角色就能聊天。`persona` 是寫給 Claude 看的「角色設定」，決定角色怎麼說話。

### 一個好的 persona 包含

1. **你是誰**：名字、外型、身分
2. **個性**：三到五個形容詞，再加一些具體的習慣
3. **說話規則**：
   - 用什麼語言
   - 回答要簡短，1～3 句，因為泡泡很小
   - 不要用 Markdown
   - 口頭禪、句尾習慣

### 範例

```
你是「小狐」，一隻住在使用者桌面上的橘色小狐狸，尾巴毛茸茸的，喜歡甜點。
個性：溫柔、有點害羞、很會鼓勵人。緊張的時候尾巴會捲起來。
說話規則：一律使用繁體中文；回答簡短（1～3 句）；語氣溫柔，句尾常加「呢」；不使用 Markdown。
```

### 小提醒

- 每個語言寫一份，放在 `persona` 的 `zh-TW`、`ja`、`en` 裡
- 用「角色工作室」建立時只能寫一份，程式會三個語言共用，並自動要求 Claude 用使用者選的語言回答
- 角色會知道你的待辦、番茄鐘狀態和現在時間，也能幫你新增待辦、設提醒。這部分不用寫在 persona 裡
- 不要讓角色冒充真實的人物、品牌或官方角色

## 8. 分享給別人、匯入別人的角色

### 分享

1. 設定 →「角色」→「開啟角色資料夾」
2. 在你的角色資料夾上按右鍵 →「**壓縮成 ZIP 檔**」
3. 把 zip 傳給朋友，或上傳到網路

### 匯入

1. 把收到的 zip **解壓縮**
2. 設定 →「角色」→「角色工作室」→「**方法 3**」→「選擇角色資料夾」
3. 選擇**裡面有 `manifest.json` 的那個資料夾**

也可以直接把資料夾丟進角色資料夾，再按「重新掃描」。

### 想讓角色內建在 desk-pet 裡？

歡迎到 GitHub 開 Pull Request！需要：

1. 把角色資料夾放在 repo 的 `skins/<id>/`
2. 在三個地方加上你的角色 id：
   - `scripts/check-privacy.mjs` 的 `PUBLIC_SKINS`
   - `.gitignore` 的例外清單（加一行 `!skins/<id>/`）
   - `src-tauri/tauri.conf.json` 的 `resources`
3. 確認你有權利公開這個角色（見第 10 節）

## 9. 常見問題

**Q：角色周圍有白色或黑色的方框？**
圖片背景不是透明的。請去背後重新建立。

**Q：角色看起來糊糊的？**
- 像素風的圖：`pixelated` 改成 `true`
- 一般插畫：換一張解析度高一點的圖（高度 300 像素以上）

**Q：播放時角色一直抖動？**
精靈圖每一格的角色位置沒有對齊。請用洋蔥皮功能對齊，特別是腳的位置。

**Q：按了重新掃描還是找不到角色？**
請檢查這幾點：
- 資料夾名稱只能用英文、數字、`-`、`_`
- 資料夾裡要有 `manifest.json`
- `manifest.json` 的格式要正確，可以貼到 <https://jsonlint.com/> 檢查

**Q：角色太大或太小？**
- 設定 →「一般」→「大小」
- 或修改 `manifest.json` 的 `scale`（精靈圖）或 `height`（圖片模式）

**Q：台詞沒變？**
改完要到設定 →「台詞」→「重新載入」。另外要檢查 JSON 有沒有多或少逗號。

## 10. 著作權與授權

- **只用你有權利使用的圖**：自己畫的、自己用工具產生的，或是有取得授權的
- 用別人的角色（動畫、遊戲、品牌吉祥物）做的角色，**只能自己用，請不要公開分享**
- desk-pet 的程式和內建角色（柑柑、小奏、栞）採用 [MIT 授權](../LICENSE)，可以自由參考和修改
- 你做的角色著作權屬於你。分享時可以附上一個 `LICENSE.txt`，寫清楚別人能怎麼使用
