# キャラクター制作ガイド

desk-pet のオリジナルキャラクターの作り方と、共有のしかたをまとめました。**プログラミングの知識はいりません。**

> ほかの言語：[繁體中文](CHARACTER_GUIDE.md)｜[English](CHARACTER_GUIDE.en.md)

---

## 1. 作り方は3つ

設定 →「**キャラクター**」タブ →「**キャラクター工房**」。

| 方法 | 向いている人 | 用意するもの | 仕上がり |
|---|---|---|---|
| **方法 1：画像から作る** | 絵が描ける・キャラの絵がある | 背景透過 PNG を1枚以上 | 跳ねる・揺れる・つぶれる・絵文字の効果を自動で追加 |
| **方法 2：ドット絵スプライト** | ドット絵で全部の動きを描きたい | ドット絵ソフト | 描いたコマどおりに再生、いちばん細かい |
| **方法 3：取り込む** | 共有されたキャラをもらった | キャラクターフォルダ | そのまま使える |

作ったキャラクターは `%APPDATA%\tw.deskpet.kankan\skins\` に保存されます（「キャラクターフォルダを開く」で開けます）。

---

## 2. 方法 1：画像から作る（いちばん簡単）

1. キャラクターの画像を用意します：
   - **PNG・背景透明**（透明でないと四角い枠が出ます）
   - **左向き**（右へ歩くときは自動で反転）
   - **高さ 200〜600px**
   - 上下左右の余白は少なめ、足が画像の下の端につくように
2. 設定 →「キャラクター」→「キャラクター工房」→「**方法 1**」
3. 名前を入れて「**待機 \***」の画像を選ぶ（必須）
4. ほかの動作の画像は**なくても OK**
5. 「チャットの性格」「キャラクター紹介」は任意
6. 「**キャラクターを作る**」を押すと、自動で切り替わります

| 動作 | 自動で付く効果 |
|---|---|
| 待機・すわる | ゆっくり呼吸 |
| 歩く | ぴょこぴょこ跳ねて左右に揺れる |
| 寝る | 少しつぶれて 💤 |
| つままれる | ゆらゆら揺れて 💦 |
| よろこぶ | ジャンプして ✨ |
| 考え中 | 首をかしげて 💭 |
| なでなで | ぷにっとつぶれて 💕 |
| おやつ | 小さく跳ねて 🍪 |

動作ごとに表情を変えた画像（寝るときは目を閉じる、など）を用意すると、もっとかわいくなります。

- ドット絵の画像なら、`manifest.json` の `"pixelated"` を `true` にするとくっきり表示されます
- 大きさは `manifest.json` の `"height"`（標準 128）か、設定「一般」の「大きさ」で変えられます

---

## 3. 方法 2：ドット絵スプライトを描く

1. 設定 →「キャラクター」→「キャラクター工房」→「**方法 2**」→「テンプレートを作ってフォルダを開く」
2. フォルダの中身：
   - `sprite.png`：**ここに描く**（背景は透明のまま）
   - `guide.png`：ガイド用のマス目（色分けされた行、濃い横線が地面）
   - `manifest.json`：キャラクター設定
   - `lines/zh-TW.json`：専用セリフの例
3. [Aseprite](https://www.aseprite.org/)、[LibreSprite](https://libresprite.github.io/)、[Piskel](https://www.piskelapp.com/)（ブラウザ）などで描いて保存
4. desk-pet で「**再スキャン**」→ キャラクターを選ぶ

```
      0コマ目  1コマ目  2コマ目  3コマ目
0行目  idle    idle    idle    idle     ← 待機
1行目  walk    walk    walk    walk     ← 歩く
2行目  sleep   sleep                    ← 寝る
3行目  drag    drag                     ← つままれる
4行目  react   react   react   react    ← よろこぶ
5行目  think   think   think   think    ← 考え中
6行目  pet     pet                      ← なでなで
7行目  eat     eat                      ← おやつ
8行目  sit     sit                      ← ウィンドウの上にすわる
```

- 1マス **32×32**、4倍で表示されます
- 64×64 で細かく描きたい場合は、次の3つを変えます：
  1. 画像サイズを2倍にする
  2. `frameWidth` と `frameHeight` を 64 にする
  3. `scale` を 2 にする
- **左向き**。足は guide.png の地面の線にそろえる
- コマごとにキャラの位置をそろえないとガタつきます。オニオンスキン機能を使いましょう
- コマ数は `frames`、速さは `fps` で変えられます。描かない動作は行ごと消せば、近い動作で代用されます

---

## 4. 使われる動作

| 名前 | いつ | ないときの代わり |
|---|---|---|
| `idle` | ふだん（**必須**） | ─ |
| `walk` | 歩き回る | idle |
| `sleep` | 長く席を外したとき | idle |
| `drag` | つままれる・ウィンドウから落ちる | idle |
| `react` | クリック・ToDo 完了 | idle |
| `think` | Claude の返事を待つ | idle |
| `pet` | なでなで | react |
| `eat` | おやつ | react |
| `sit` | ウィンドウの上にすわる | idle |

## 5. manifest.json の項目

| 項目 | 説明 |
|---|---|
| `name` | 名前（必須） |
| `names` | 言語ごとの名前 `zh-TW` / `ja` / `en` |
| `bio` | 言語ごとの紹介文（設定の「について」に表示） |
| `persona` | 言語ごとのチャットの性格 |
| `mode` | `"image"` で画像モード、書かなければスプライトモード |
| `image` / `frameWidth` / `frameHeight` / `scale` / `animations` | スプライトモード用 |
| `images` / `height` / `pixelated` | 画像モード用（`images` は最低 `idle` が必要） |

画像は PNG・JPG・WebP・GIF（GIF は1コマ目のみ）に対応しています。ファイル名は同じフォルダ内のものだけ指定できます。フォルダ名（= キャラクター ID）に使えるのは英数字・`-`・`_` です。

## 6. 専用セリフ

キャラクターフォルダに `lines/ja.json` を作ります：

```json
{
  "greeting": ["こんにちは！今日もよろしくね。"],
  "click": ["ん？呼んだ？"],
  "todo_done": ["できたね！すごい！"]
}
```

- 書いたカテゴリだけが共通セリフを上書きします
- 最後の要素のあとにカンマを付けないでください
- 書き換えたら、設定 →「セリフ」→「再読み込み」

カテゴリの一覧は[繁體中文版の第6節](CHARACTER_GUIDE.md#6-寫角色專屬台詞)と同じです（`greeting`、`idle`、`busy`、`late_night`、`todo_done`、`pet`、`feed` など）。

## 7. チャットの性格（persona）

API キーを設定すると、キャラクターとおしゃべりできます。`persona` は Claude に渡すキャラクター設定です。

1. **だれか**：名前・見た目・正体
2. **性格**：形容詞を3〜5個と、具体的なクセ
3. **話し方**：何語で話すか、短く（1〜3文）、Markdown を使わない、口ぐせ

```
あなたは「こぎつね」。ユーザーのデスクトップに住むオレンジ色の子ぎつねで、甘いものが大好き。
性格：やさしくて、少し恥ずかしがり屋。緊張するとしっぽを丸める。
ルール：必ず日本語で話す；返事は短く（1〜3文）；やわらかい口調；Markdown は使わない。
```

実在の人物やブランド、公式キャラクターになりすまさないようにしてください。

---

## 8. 共有と取り込み

- **共有するとき**：キャラクターフォルダを右クリック →「ZIP ファイルに圧縮」して渡す
- **取り込むとき**：zip を展開してから、キャラクター工房の「**方法 3**」で `manifest.json` が入っているフォルダを選ぶ
- desk-pet に最初から入れたいときは、GitHub で Pull Request を送ってください（手順は繁體中文版の第8節）

---

## 9. よくある質問

- **四角い枠が出る** → 背景が透明ではありません
- **ぼやける** → ドット絵なら `pixelated: true`。イラストなら高さ 300px 以上の画像を使う
- **ガタガタ動く** → コマごとの位置、特に足の位置をそろえる
- **見つからない** → フォルダ名は英数字だけ？`manifest.json` はある？ JSON の書き方は正しい？（<https://jsonlint.com/> で確認できます）
